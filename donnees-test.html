Vos données sur SAMGO TEST

Information sur le prototype — 28 octobre 2026. Cette page décrit le fonctionnement technique actuel et ne constitue pas encore une politique de confidentialité juridique complète. Le responsable légal, les coordonnées de contact définitives, les bases légales, les durées de conservation et les procédures d'exercice des droits restent à formaliser avant un lancement réel.

Quelles données sont traitées ?

  • Comptes : adresse e-mail et identifiant de compte ; le mot de passe est transmis à Supabase Auth par connexion sécurisée, sans être publié dans le dépôt GitHub.
  • Candidatures chauffeur : nom d'affichage, statut et date de candidature de TEST. Ne transmettez pas de permis, carte d'identité, selfie ni justificatif sensible sur cette démonstration.
  • Annonces fictives : lieux textuels fictifs, distance et prix indicatifs, ainsi qu'une position client approximative (arrondie à deux décimales) en cas de publication volontaire avec accord GPS.
  • Conversations et avis : messages, notes, commentaires, choix et étapes de courses de simulation enregistrés pour les comptes concernés. Ne saisissez aucune vraie adresse, pièce d'identité, téléphone ou information bancaire.
  • Signalements : catégorie et description saisies volontairement depuis la page Aide et signalement.

Comment fonctionne la localisation ?

Le chauffeur demande lui-même sa position depuis l'écran Missions. Sur le site, le GPS du navigateur est utilisé ; dans l'application Android/iPhone de test, le composant GPS natif est sollicité uniquement après cette action. La position est utilisée localement pour calculer les distances approximatives aux annonces. Une zone arrondie à environ 0,1 degré sert au filtrage côté serveur : le GPS précis du chauffeur n'est pas enregistré dans la table des annonces.

Après 15 minutes sans nouvelle autorisation ou mise à jour volontaire, la recherche cesse de réutiliser cette position. Le bouton « Arrêter la recherche GPS » efface la position locale dans ce module. Il ne supprime pas les autorisations accordées dans les réglages du navigateur ou du téléphone. Si la précision GPS annoncée est trop faible (plus de 5 km d'incertitude), SAMGO refuse cette mesure pour éviter un affichage trompeur.

Attention : quand un client publie une annonce fictive, des coordonnées arrondies à deux décimales sont enregistrées dans le service de test. L'annonce cesse normalement d'être proposée à la recherche après environ deux heures, mais cela ne veut pas dire que l'enregistrement est automatiquement supprimé de la base.

Où sont les données ?

Le prototype s'appuie sur GitHub Pages pour le site et Supabase pour les comptes et enregistrements de test. Les règles d'accès à la base (RLS) sont activées, mais le prototype n'a pas encore subi un audit de sécurité complet.

Les jetons de session du navigateur sont conservés dans sessionStorage lorsque ce stockage est disponible. Le service worker de SAMGO ne conserve que la page neutre « hors connexion », pas les messages, comptes ou réponses API. Les parcours Stripe sont exclusivement des simulations ou un environnement de test, sans paiement réel activé.

Contrôler ses données de test

Vous pouvez retirer une annonce de test sans choix de chauffeur depuis votre espace. Vous pouvez aussi vous déconnecter, effacer la simulation locale et révoquer la localisation depuis les paramètres du téléphone. Cela ne supprime pas forcément les informations déjà stockées chez le prestataire.

Dans Mon compte, vous pouvez désormais demander une copie partielle des données de TEST visibles par votre compte : annonces, simulations, échanges, avis et opérations fictives. Le fichier est téléchargé localement dans le navigateur ou copié dans l'application mobile quand c'est possible. Aucun jeton de connexion ni position GPS précise ne doit être exporté. Gardez cette copie privée.

Cet export est limité par les résultats disponibles dans le prototype et ne constitue pas un export complet de vos données personnelles. Le mécanisme officiel d'accès, de rectification et de suppression des comptes reste à concevoir et à vérifier. Évitez d'utiliser cette démonstration avec de vraies données sensibles. Consultez Aide et signalement pour remonter un problème de test ; ce support n'est pas surveillé en permanence.
